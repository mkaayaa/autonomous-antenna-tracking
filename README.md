# Autonomous Antenna Tracking System

A UAV antenna tracking project combining computer vision, embedded computing, and custom PCB hardware.

**Program:** TÜBİTAK 2209-B undergraduate research project

## Objective

The project aims to detect and track UAVs and use target information to support autonomous antenna pointing.

## Project Scope

| Area | Intended role |
| --- | --- |
| Computer vision | YOLOv8-based target detection |
| Embedded computing | Raspberry Pi 5 integration for the vision application |
| Custom PCB hardware | Communication and antenna tracking control |
| System integration | Coordination of the vision, communication, and control components |

These items describe the project scope. Implementation details and measured results will be documented alongside the corresponding project files.

## Repository Status

This repository currently contains this overview and a Python `.gitignore`.

Source code, model files, PCB design files, setup instructions, and test results have not yet been published here. The repository does not currently provide a runnable implementation.
